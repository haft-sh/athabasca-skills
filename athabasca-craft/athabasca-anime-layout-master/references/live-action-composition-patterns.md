# Live-action composition patterns reference

Use this reference for live-action shot design when the user is shaping motifs, screen grammar, and continuity devices across a sequence.

## Brand-name substitution rule

Scripts may contain potentially trademarked product names. Flag them before committing to shot breakdown work. Propose 3–5 fictional alternatives before the user picks. Treat substitution as a draft decision until confirmed.

## Screen UI as narrative device

A laptop or phone screen can function as a cinematic insert, not just UI illustration.

Grammar:
- institutional UI frame or information panel = authority
- full-color image inside that frame = the thing the character confronts
- native-UI framing works better than an arbitrary external screen
- pure insert: no character in frame when the screen itself is the subject

Key principle: the emotional weight often comes from the gap between the mundane interface and the scale of the revelation.

## Sound motif ring structure

A small sound planted innocently at the top of the film can return later in a darker context.

Track:
- first innocent appearance
- silent visual presence through later beats
- transformed return

Key principle: do not overstate the sound. The audience should feel the return more than consciously notice it.

## Dark screen as mirror rule

A TV, monitor, or phone screen that is OFF can serve as a pure reflection surface. Once a screen is established as OFF/MIRROR in a scene, do not casually turn it on in the same sequence or the mirror function collapses.

## Indicator-light continuity arc

A wearable or device light can carry emotional meaning through controlled changes in color or pulse behavior.

Key principle: one meaningful shift per act is usually enough. If the indicator changes constantly, it stops carrying narrative weight.

## VO remix workflow

When revising a voice-over line that structurally anchors a sequence:
1. Present several options with surrounding script context.
2. Label tonal register.
3. Recommend the best option with reasoning.
4. Wait for confirmation.
5. Only then patch the shot-breakdown or script document.

## Continuity locks table

For projects with visual or audio throughlines, keep a single continuity-locks table that tracks motif state, first appearance, and later reappearances. Update it whenever a new throughline element is introduced.

## Document amendment workflow

When the user identifies changes in a shot breakdown:
1. Discuss with specific line or script references before touching the document.
2. Get confirmation on the approach.
3. Patch only the affected shots and continuity locks.
4. Re-upload as a new versioned asset with a provenance note.
