# Comedy structure and visual-payoff patterns

Use this reference for comedy-script development when the work sits at the intersection of satire, visual payoff, and shot-by-shot narrative logic.

## Brand-name substitution

If a script uses a likely trademarked real company or product name:
1. Generate options across sincere → silly → absurd range.
2. Present brief rationale for the best picks.
3. Confirm the chosen substitute before propagating it across documents.

Key principle: the joke usually lands in execution, not in the brand name itself.

## VO line timed to image payoff

When a voice-over line describes or reframes an image, time the line to cut directly to that image rather than placing it vaguely nearby.

Key principle: the hinge is line → hard cut → image payoff.

## Reveal through established interface

If a revelation is delivered through a screen, use the screen or interface already established in the scene rather than inventing a less plausible display source.

Key principle: the familiar interface makes the reveal feel more inevitable and more devastating.

## Off-screen versus active-screen grammar

If one screen is established as OFF / reflective and another as ACTIVE / informational, preserve that contrast. Mixing those grammars carelessly weakens both beats.

## Repeating visual device twice

When using the same visual device twice in one sequence:
1. first instance should feel innocuous
2. second instance uses the same format but changed content
3. the unchanged frame grammar makes the new meaning land harder

## Escalation architecture

Not every beat in a comedy escalation has to be funny on the surface. Quiet, ominous, or devastating beats can still be part of the comedy engine if they advance the same satirical logic.

## Document amendment workflow

For structural comedy revisions:
1. present proposed changes as discussion points first
2. get confirmation before rewriting full documents
3. upload a new version with `supersedes` metadata when replacing a prior canonical draft
4. update downstream shot breakdowns or prompt lists in the same amendment pass
