# Environment-reveal breakaway iteration notes

Use this reference when a destination environment prompt is over-locked to the previous location because the continuity anchor is too strong.

## Problem pattern
A successful interior or earlier-scene anchor can preserve continuity so aggressively that the model keeps reproducing the old geometry when the shot needs to reveal a new destination space.

## Working sequence
1. Start with the continuity-preserving reference to test whether the destination can be reached directly.
2. If the old geometry keeps winning, run a text-only breakaway prompt that describes only the destination reveal.
3. Once the destination layout exists, reintroduce the continuity object or ritual prop with explicit spatial constraints.
4. If Midjourney still over-locks the prior space, switch to a model that follows spatial instructions more literally.

## Key lesson
Continuity anchors are useful until they become cages. When the destination geography matters more than exact continuity, break away first and re-anchor second.
