# Character-in-environment lab — round 2

**Date:** 2026-05-14

Round 2 focused on what happens after the basic dual-reference pattern works and the user wants stronger room geography, scale perception, and more grounded light.

## Findings
- environment-led prompts often improve spatial believability
- dual-reference prompts still win when identity drift is unacceptable
- env-only references can produce more atmospheric images, but usually at the cost of character specificity
- grounded lighting language helps the environment feel lived-in rather than generic

## Practical guidance
- if the first round already proved the identity lock, spend the second round tuning room geography and light rather than rewriting the whole character description
- compare env-only versus dual-reference outputs on purpose; they solve different problems
- when scale feels wrong, state the character-to-room relationship directly in text
