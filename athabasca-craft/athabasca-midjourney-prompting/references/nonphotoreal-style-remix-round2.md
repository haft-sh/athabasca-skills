# Non-photoreal style remix pattern

Use this reference when the user wants another visual-development prompt round based on already approved Midjourney grids, but needs the next round to move decisively away from stylized-photographic rendering.

## User-facing intent to preserve
- Keep the same comparison composition when the purpose is fair A/B review.
- Remix from approved grids rather than resetting from zero.
- Push away from realism in anatomy, surface modeling, and photographic shading.
- Make subjects read as assembled from simple shapes rather than fully rendered bodies.
- Prefer efficient visual shorthand over meticulous realism.
- Use limited palettes when the user wants a stronger handmade or graphic read.

## Prompt language that worked
Use positive, final-image descriptions such as:
- `bold elementary 2D shapes`
- `shapes hint at the subject instead of rendering it`
- `crude efficient shapes`
- `visual shorthand, symbols not anatomy`
- `made from torn paper shapes`
- `visible glue edges, paper wrinkles, kraft-paper texture`
- `fat wet brushstrokes, paint splotches, splattered canvas texture`
- `limited tan black leaf green dusty blue and cream palette`

Avoid overusing negative-parameter language. Prefer describing the wanted result rather than just prohibitions.

## Strong variant classes
For a 20-prompt remix round, mix:
1. Painterly / splatter
2. Paper / collage
3. Graphic print
4. Primitive / folk geometry
5. Abstract symbolic silhouettes
6. Wildcard handmade materials

## Review queue rule carried forward
When showing the resulting MJ grids one by one, after any chosen upscales complete, immediately show the next grid. In this queue context, bare `next` means skip the current grid and advance.
