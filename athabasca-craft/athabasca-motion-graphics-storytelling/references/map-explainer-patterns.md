# Map Explainer Patterns

Use this when a migration/dispersal/isolation map needs to feel like a directed documentary insert instead of a static infographic.

## Core rule
A map beat should usually teach **one** of these at a time:
1. origin / established range
2. route opening
3. route traversal
4. corridor closure
5. post-split divergence

Trying to teach all five in one held frame usually produces clutter.

## Recommended shot structures

### Pattern A — 3-beat single sequence
Best for short inserts around 12-20 seconds.

1. **Origin beat**
   - Quiet map
   - Spotlight or crop on source region
   - One short caption or label only
   - Goal: establish where the story starts

2. **Crossing beat**
   - Route traces across the corridor
   - Camera pushes toward the corridor or destination
   - One compact corridor label/card
   - Goal: make the path itself the focal event

3. **Split beat**
   - Water/cut/divider closes the corridor
   - Hold long enough for the closure to read
   - Species or population labels appear after the closure
   - Goal: make separation legible before naming outcomes

### Pattern B — 2-shot documentary insert
Use when one frame cannot hold the argument cleanly.

**Shot 1: route opens and crosses**
- No species labels
- Minimal text
- Strong directional motion
- End on arrival or on the corridor itself

**Shot 2: corridor closes, outcomes appear**
- Start tighter on Beringia / chokepoint
- Show water closure first
- Then widen or recompose to reveal separated populations

This pattern is usually better than forcing origin, route, closure, and taxonomy into a single composition.

## Placement rules
- Prefer **one active caption zone** per beat
- Keep labels near the geography they identify
- If labels must be far from the evidence, use timing or guide lines to bridge the gap
- Do not place important text in all four corners while the route plays through the middle

## Focal-order examples

### Good
- source dot → route head → corridor card
- corridor closure → broken route → species labels

### Bad
- title block + time chip + legend + lower caption + species cards all live at once
- base map arrows competing with animated path of a different color/weight

## Repair moves

### If the map feels static
- animate the route head, not just the full line
- push in toward the chokepoint
- dim the rest of the map harder
- cut to a tighter second shot

### If the map feels cluttered
- delete the legend and encode meaning in sequence instead
- reduce text to one sentence per beat
- postpone species labels until after the split reads
- remove background arrows if the animated path already teaches direction

### If the eye path is weak
- use a spotlight or crop to define the dominant region
- animate only one explanatory object at a time
- hold after the key event so the viewer can cash out the meaning

## Session-derived lesson
From the Beaver Evolution map pass:
- v01 failed because it behaved like a static infographic with captions in multiple corners and no enforced eye path
- v02 improved by using a beat sheet, one active caption strip, route-first staging, and delayed species labels
- v03 exposed a stricter rule: if the base art already contains arrows, those arrows pre-answer the shot and will usually fight any animated overlay. Do not animate a second path system on top of a solved map
- a curved white overlay that does not track coastline or land exposure reads like air travel, not migration. For land-bridge stories, either trace the real corridor tightly or omit the route entirely
- for sea-level explanations, a low-water plate transitioning into a matching high-water plate is often clearer than adding more arrows, labels, or divider graphics
- remaining limitation: even an improved single-shot map can still be too text-heavy; default to a 2-shot structure sooner when the corridor event is the real story
