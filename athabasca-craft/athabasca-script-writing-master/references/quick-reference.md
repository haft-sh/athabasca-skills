# Script Writing Master Quick Reference

## Master question

What does the protagonist want, what stops them, what choice changes them, and how does the ending prove it?

## Fast diagnosis

If the draft feels boring, check conflict.
If it feels confusing, check want and causality.
If it feels preachy, check theme-as-dialogue instead of theme-as-choice.
If it feels slow, check scene turns.
If it feels thin, check stakes and specificity.
If it feels overstuffed, check short-film scope.
If it feels generic, check character contradiction and image system.
If it feels wrong for kids, check emotional legibility and concrete behavior.

## Core terms

- Want: visible goal
- Need: deeper growth
- Flaw: active self-defeating strategy
- Inciting incident: disruption of balance
- Antagonism: resistance to desire
- Stakes: cost of failure
- Crisis: difficult choice
- Climax: irreversible action
- Resolution: new balance
- Turn: change inside a scene
- Subtext: what is meant but not said

## Short film rule of thumb

One protagonist. One situation. One conflict. One turn. One ending image.

## Children’s rule of thumb

Name the feeling, show the body, test the flawed behavior, practice the new behavior, end with a memorable repeatable cue.

## Scene test

A scene earns its place if:

- someone wants something
- something resists
- tactics change
- the scene turns
- the story cannot work without it

## Dialogue test

A line earns its place if it:

- pursues an objective
- hides or reveals pressure
- changes the relationship
- creates friction
- is funnier, sharper, simpler, or more character-specific than plain information

## Rewrite priority

1. Premise and protagonist
2. Want, need, flaw
3. Conflict and stakes
4. Structure and ending
5. Scene turns
6. Dialogue and subtext
7. Polish

## Standard output for script critique

1. One-sentence diagnosis
2. Current dramatic engine
3. Scores
4. What works
5. What fails
6. Priority rewrite plan
7. Concrete fixes
8. Optional variants

## Standard output for ideation

1. Core emotional promise
2. Protagonist / want / need / flaw
3. Dramatic situation
4. Beat outline
5. Ending image
6. Variants
7. Recommended version
