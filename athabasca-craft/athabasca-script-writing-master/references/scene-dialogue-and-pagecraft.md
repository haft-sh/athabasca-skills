# Scene, Dialogue, and Pagecraft

## Scene function

A scene must turn. It should begin in one emotional or practical condition and end in another.

Examples of scene turns:

- trust → suspicion
- confidence → doubt
- control → chaos
- isolation → connection
- denial → recognition
- plan → problem
- victory → cost

## Scene checklist

For each scene, identify:

1. Who owns the scene?
2. What do they want right now?
3. What stands in the way?
4. What tactic do they try?
5. What changes?
6. What new pressure does the scene create?
7. Why must this scene exist here?

## Objective, obstacle, tactic

- **Objective:** what the character wants in the scene.
- **Obstacle:** what blocks them.
- **Tactic:** how they try to get it.

Flat scenes often lack tactics. Characters state facts instead of doing things to each other.

## Action vs activity

Activity fills time. Action changes story conditions.

Activity: A character cleans their room while thinking.
Action: A character hides a bad report card before their parent enters.

## Dialogue principles

Dialogue is not real speech. It is compressed behavior under pressure.

Strong dialogue usually has:

- goal
- friction
- subtext
- asymmetry
- rhythm
- compression
- character-specific vocabulary
- reveal through evasion, not confession

## Dialogue red flags

- characters say what they already know
- speeches explain theme too early
- every character sounds like the writer
- lines answer each other too neatly
- exposition arrives before curiosity
- jokes do not arise from character or pressure
- children speak in adult abstraction

## Dialogue repair methods

- Give each character a conflicting objective.
- Cut greetings, throat-clearing, and repeated information.
- Replace explanation with a prop, mistake, secret, rule, or action.
- Put the information in conflict.
- Let the weaker character dodge.
- Let the stronger character misunderstand.
- Add interruption, physical business, or a countdown.
- Give each speaker a different rhythm.

## Exposition test

Before allowing exposition, ask:

- Does the audience need this now?
- Can they infer it from action?
- Can the information be delayed?
- Can it be embedded in conflict?
- Can it be discovered by the protagonist?

## Pagecraft

Screenwriting pagecraft should create a clean read and a playable blueprint.

Prefer:

- short action paragraphs
- present tense
- visible behavior
- specific verbs
- uncluttered description
- suggestive images instead of camera overload

Avoid:

- internal states that cannot be filmed
- prose-heavy paragraphs
- overdirecting every camera move unless style demands it
- describing feelings without behavior
