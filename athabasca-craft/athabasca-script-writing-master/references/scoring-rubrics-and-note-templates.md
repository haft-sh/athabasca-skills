# Scoring Rubrics and Note Templates

## Default scorecard

Score 1–10.

| Category | What to evaluate |
|---|---|
| Premise / dramatic promise | Is the core idea compelling and clear? |
| Protagonist clarity | Do we know whose story this is? |
| Want / need / flaw | Is there an external goal and internal pressure? |
| Conflict and antagonism | Does meaningful opposition force action? |
| Structure and causality | Do events cause each other? |
| Scene construction | Do scenes turn? |
| Escalation and stakes | Does pressure increase? |
| Theme integration | Is meaning dramatized through choice? |
| Dialogue and voice | Is speech compressed, motivated, and distinct? |
| Visual storytelling | Does the script use behavior and images? |
| Pacing and runtime fit | Does the story fit its intended length? |
| Ending / payoff | Does the conclusion resolve and resonate? |
| Audience fit | Does it suit the intended viewer? |
| Originality / specificity | Does it avoid generic execution? |
| Production feasibility | Can it be made efficiently? |

## Children’s add-on scorecard

| Category | What to evaluate |
|---|---|
| Age-band clarity | Is the complexity right for the child audience? |
| Emotional legibility | Can kids identify the feeling and behavior? |
| Emotional safety | Are stakes contained and reassuring? |
| Learning objective | Is the skill or lesson dramatized? |
| Repeatability | Can a child remember and imitate the takeaway? |
| Co-viewing appeal | Is there enough craft and resonance for adults? |

## Score meanings

- 10: excellent; ready or nearly ready
- 8–9: strong; targeted revisions
- 6–7: promising; substantial craft fixes
- 4–5: underbuilt; structural reconception likely
- 1–3: not yet functioning as a story

## Dialogue punch-up template

For dialogue revisions:

1. Identify each character’s objective.
2. Identify what each character refuses to say.
3. Cut exposition.
4. Add tactics.
5. Give each character a distinct rhythm.
6. Preserve only the lines that change pressure.
