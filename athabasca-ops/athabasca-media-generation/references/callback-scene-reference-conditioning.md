# Callback-scene reference conditioning

Use this note when generating scenes that visually rhyme with an earlier ritual, gesture, or private beat while remaining grounded in a new public-world context.

## Reference pattern

For callback shots, the strongest conditioning set is often:
1. current-world character reference
2. one exact callback insert reference matching the beat
3. destination environment reference

This works better than using only earlier-scene references, because the new shot needs to rhyme with the original beat rather than recreate the original location.

## Shot-type routing inside the same scene

- re-entry / line / drill / reaction shots: character ref + destination environment ref + peer/silhouette ref
- hand-placement insert: character ref + exact insert ref + environment ref
- breath / glow recall: character ref + exact insert ref + environment ref

## Prompting rule

State explicitly that:
- the callback is a small repeatable action under stress, not a transformation spectacle
- the new setting should remain socially or narratively grounded
- the callback should rhyme with the earlier insert while staying believable in the current location

## Why this matters

Without the exact callback insert references, the model tends to drift toward generic coverage and loses the specific hand-placement, breath, or gesture logic that gives the beat narrative payoff.
