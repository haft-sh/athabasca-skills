# Dialogue Helper Groups

Use a helper group when a source shot is compositionally useful but its dialogue is too long for the parent lane.

## Parent group

Keep the fast visual progression. End it at a stable continuity handoff:
- screen direction;
- character scale and relative positions;
- prop state;
- selected last frame if available.

## Helper group

Give the helper a direct name, such as `Group B-Helper — the guardian Monologue and Echo`.

Include:

1. **Visual master** — no complete dialogue required; supplies cutaway coverage.
2. **Carrier A** — first semantic thought, usually 2.5–3s.
3. **Carrier B/C** — short accusation or response phrases, usually 1.5–2s each.
4. **Reaction carrier** — other character silent; dialogue may be off-screen.
5. **Insert / bridge** — prop, ground, shadow, or environment image that makes an edit feel intentional.

Each carrier states one speaker, one action, one framing idea, its intended duration, and a continuity/cut instruction. Avoid assigning several sentences, a large action change, and a camera move to a single short clip.

## Review hygiene

Render the helper as its own navigable packet group. Do not hide the newly expanded local shots in a generic appendix: reviewers need to see the group split where they inspect the parent sequence.
