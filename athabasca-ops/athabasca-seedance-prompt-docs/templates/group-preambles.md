# Seedance Group Prompt Preambles

Each group's Seedance prompt must start with a preamble that integrates `@imageN` tags as instructions. Use these templates.

## 2012-era groups (A, D, G, M partial)

```
I want you to generate the following scenes for our live-action cinematic satirical comedy film.

The setting is the spartan writing room in @image2. Character: @image1. Typewriter: @image3. [Additional props as needed].
N shots. Duration per shot: ~X.Xs. Transition: hard cuts between all shots.
```

## 2026-era groups (B, C, E, F, H, I, J, K, L, M partial, N)

```
I want you to generate the following scenes for our live-action cinematic satirical comedy film.

2026 character: @image5. [Location: @imageN]. [Additional props as needed].
N shots. Duration per shot: ~X.Xs. Transition: hard cuts between all shots.
```

## Mixed-era groups (B has both 2012 eyes + 2026 couch, G has 2012 war room, M has 2012 hunger + 2026 sandwich)

```
I want you to generate the following scenes for our live-action cinematic satirical comedy film.

2012 character: @image1. 2026 character: @image5. [Locations and props as needed].
N shots. Duration per shot: ~X.Xs. Transition: hard cuts between all shots.
```
