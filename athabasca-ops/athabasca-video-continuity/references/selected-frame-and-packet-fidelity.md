# Selected-frame continuation authority

When a creator selects a frame from an accepted predecessor clip as the desired state for a new clip, the extracted frame is the first-frame authority, not a secondary identity image.

- Persist the extracted frame through Athabasca and use its public URL.
- Put it first in reference order and say generation starts from its visible state.
- Do not simultaneously attach an older whole-video continuation reference unless the creator explicitly wants its motion history to override the selected frame.
- For a one-character effect (for example, a puff/dissolution), identify the sole changing character, keep all others visible and unchanged, and state the effect originates from that character’s current on-screen body.

## Packet review fidelity

A rendered prompt packet must clone the source packet’s group/card structure, source-shot range, director note, reference order, and full copy-paste block. Do not substitute a generic dispatch-report layout. Narrow corrections must be visibly additive and must not summarize or replace the approved source.
