# Premium visual audit deliverable

Use this when the user wants more than critique text — they want a presentation-quality review package.

## Deliverable shape

Produce one publishable HTML artifact that combines:
- executive summary
- prioritized findings
- screen-by-screen critique
- redesign recommendations
- generated visual concepts
- before/problem illustration for each major flaw
- after/proposal illustration for each major flaw
- implementation backlog / next actions

## Workflow

1. Capture the real product surfaces first.
2. Critique the actual UI before generating any redesigns.
3. Identify the major flaws worth illustrating visually.
4. Generate high-quality concept images for each major flaw:
   - one **before/problem** image that makes the current issue legible
   - one **after/proposal** image that shows the recommended fix
5. Assemble the screenshots, critique, and generated visuals into a single HTML review artifact.
6. Publish or export the artifact to a location the user can open directly.

## Quality bar

- The generated concepts should look like premium product-design mockups, not rough wireframes.
- The images should illustrate the exact critique point: hierarchy, copy clarity, panel competition, flow confusion, etc.
- Each pair should clearly answer: **what is wrong now, and what should it become?**
- The final artifact should read like a design review handoff, not a loose collection of notes.

## Failure handling

If image generation is quota-limited or otherwise blocked:
- say so plainly
- include the completed text critique anyway
- preserve the artifact as a single HTML deliverable
- if needed, substitute polished HTML/CSS mockups for the missing generated images rather than pretending the visual set is complete
